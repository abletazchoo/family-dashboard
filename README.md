# 🏡 보통날의 우리집

가족의 하루를 한 화면에 담는 크림·파스텔 톤 가족 대시보드입니다.
서버 없이 브라우저 안에서만 동작하는 정적 웹앱이고, GitHub Pages에 그대로 올려 쓸 수 있어요.

> **이 저장소에는 가족의 개인 자료가 암호문으로만 들어 있습니다.**
> 시간표·급식·공유 일정은 `data/family-vault.enc.json` 한 파일에
> PBKDF2-SHA256(150,000회) + AES-256-GCM으로 잠겨 있고,
> 앱을 열 때 입력하는 **가족 PIN 4자리**로만 풀립니다. PIN이 없으면 열리지 않아요.

## 화면

1. **대시보드**
   - 오늘의 시간표 — 두 아이의 오늘 학교·방과후·학원·셔틀 일정을 나란히, 지금 하는 일과 다음 일정 표시
   - 오늘의 급식 — 오늘의 점심 메뉴(알레르기 번호·칼로리)와 내일 미리보기, 이번 주/월간 식단표
   - 가족 캘린더 — 월간 달력, 날짜별 일정 점, 선택한 날 일정 목록, 일정 추가·수정·삭제(여러 날 일정 지원)
   - 오늘의 날씨 — Open-Meteo 실시간 기온·최고/최저·시간대별 예보·체감/습도·미세먼지·옷차림 팁
   - 🛒 장보기 — 살 것 추가, 샀어요 체크, 삭제
   - 오늘의 저녁 — 메뉴 정하기(추천 메뉴 돌리기 또는 직접 입력), 비우기, 최근 먹은 메뉴
   - 가족 상태 — 네 사람 카드(일러스트), 눌러서 상태·이름 바꾸기
   - 가족 우체통 — 편지 쓰기, 읽었어요 토글, 삭제
   - 🐹🦉 우리집 펫 — 유온은 **햄스터**, 지온은 **올빼미**. **먹이쿠폰**으로 먹이를 줘서 키우고(**먹이 5개 = 한 레벨**), 단계 배지·먹이 진행·보유 쿠폰·명예의 전당이 펫마다 따로 쌓임. 쿠폰은 **엄마가 후추(AI)에게 말해서만** 받고, 대시보드 화면에는 쿠폰을 늘리는 곳이 없음
2. **하루 루틴** — 아이별 오늘의 루틴 체크, 다 하면 스티커 적립, 이번 주 스티커 판, 이번 주 급식, 요일별 시간표
3. **학습 챌린지·모험** — 아이별 미션과 별 모으기(새싹 → 나무 → 꽃 → 별), 오늘의 가족 모험 뽑기 → 캘린더에 담기

## 🐹🦉 우리집 펫 키우기 (유온 햄스터 · 지온 올빼미)

대시보드 맨 위에 **유온 햄스터 | 지온 올빼미** 카드가 나란히(태블릿·PC 2열, 휴대폰은 위아래) 있습니다.
**할 일·루틴과는 연결되어 있지 않습니다.** 대신 **엄마가 후추에게 말해 받는 먹이쿠폰**으로 먹이를 줘서 키워요.
**🍽️ 먹이 주기 1번 = 쿠폰 1개 사용**, **먹이 5개(FEED_PER_LEVEL)를 먹으면 한 레벨** 올라갑니다. 자정이 지나도 저절로 자라지 않아요.

| 단계 | 먹이 | 유온 햄스터 | 지온 올빼미 |
|---|---|---|---|
| Lv.1 아기 | 0~4개 | `assets/hamster-1.png`(둥지 속 갓 태어난 아기) | `assets/owl-1.png`(알) |
| Lv.2 뽀시래기 | 5개 | `assets/hamster-2.png`(둥지 밖으로 까꿍) | `assets/owl-2.png`(부화) |
| Lv.3 아장아장 | 10개 | `assets/hamster-3.png` | `assets/owl-3.png` |
| Lv.4 꼬마 | 15개 | `assets/hamster-4.png` | `assets/owl-4.png` |
| Lv.5 씩씩한 | 20개 | `assets/hamster-5.png` | `assets/owl-5.png` |
| Lv.6 모험가 | 25개 | `assets/hamster-6.png` | `assets/owl-6.png` |
| Lv.7 탐험가 | 30개 | `assets/hamster-7.png` | `assets/owl-7.png` |
| Lv.8 길잡이 | 35개 | `assets/hamster-8.png` | `assets/owl-8.png` |
| Lv.9 별빛 | 40개 | `assets/hamster-9.png` | `assets/owl-9.png` |
| Lv.10 황금 왕관 | 45개(그 뒤로 유지) | `assets/hamster-10.png` | `assets/owl-10.png` |

> 두 캐릭터 모두 3D 클레이 느낌의 **중성적이고 귀여운** 디자인이에요. 리본·핑크·긴 속눈썹은 쓰지 않고,
> **햄스터는 포유류라 알 단계가 없어요** — 1단계 짚·천 둥지에서 갓 태어나 눈 감고 자는 아기 → 2단계 둥지 밖으로 얼굴과 앞발을 내밀고 까꿍하는 뽀시래기 → 3~8단계 모험 소품(도토리·가방·나침반·랜턴) → 9단계 별빛 망토 → 10단계 황금 왕관 순서로 자랍니다.
> 지온 올빼미는 1단계 알 → 2단계 껍질을 깨고 부화 → 그 뒤로는 같은 순서예요.
> 햄스터는 버터크림 톤 배경, 올빼미는 블루그레이 톤 배경으로 이어집니다.

- **성장 계산**: `level`(1~10)과 `feedProgress`(0~4)로 정해져요. `🍽️ 먹이 주기`를 누르면 `feedUsed +1`, `feedProgress +1`,
  `feedProgress`가 5가 되면 `level +1`·`feedProgress 0`이 되고 레벨업 토스트·반짝이가 뜹니다.
- **먹이쿠폰**: `feedGranted`(후추가 준 누적) − `feedUsed`(아이가 쓴 누적) = 남은 쿠폰. 남은 쿠폰이 1개 이상이고 Lv.10이 아닐 때만 버튼이 켜집니다.
  쿠폰이 없으면 버튼이 꺼지고 **"엄마가 후추한테 말해서 먹이쿠폰을 줘야 줄 수 있어요!"** 안내가 보입니다.
- **쿠폰은 화면에서 만들 수 없어요.** 대시보드 어디에도 쿠폰을 추가·발급·수정하는 버튼이나 입력창이 없습니다.
  후추가 클라우드 동기화(`urijip-sync`)의 `feedGranted`를 올려 줄 때만 쿠폰이 늘어나요 —
  `python3 work/dashboard-feed/grant_coupon.py child1 1` (또는 `--child child2 --amount 3`)로 지급합니다.
- **먹이 진행 막대**: 카드의 막대는 이번 레벨에서 먹은 개수(`먹이 0 / 5`), 옆 글씨는 `다음 레벨까지 N개`를 보여 줘요.
- 10단계에 오르면 게이지가 꽉 찬 채 👑 축하 배지와 **새 햄스터/올빼미 키우기** 버튼이 나타납니다.
  새로 시작하면 지금 펫은 그 아이의 🏆 명예의 전당에 남고 카운트가 1 늘어납니다(남은 먹이쿠폰은 그대로).
- **어느 단계에서든 처음부터 다시** 키우려면 카드의 **이름 바꾸기** 창 아래 **Lv.1부터 다시 시작**(올빼미는 **처음(알)부터 다시 시작**)을 누르세요.
  확인 창에서 한 번 더 물은 뒤 `level 1`·`feedProgress 0`으로 돌아갑니다. 이름·명예의 전당 기록(🏆)·남은 먹이쿠폰은 그대로예요.
- 펫 그림을 누르면 하트가 뿅뿅 올라오고 단계에 맞는 응원 말풍선이 나옵니다.
- 카드 아래 1~10단계 미니 트랙에서 지금 단계와 앞으로의 모습을 한눈에 볼 수 있어요.
- 이름은 기본 **햄찌**(유온 햄스터) · **부엉이**(지온 올빼미), 각 카드의 **이름 바꾸기**로 언제든 바꿀 수 있어요.
  예전 기본 이름(몽실이·구름이·꼬북이·삐약이)을 그대로 둔 기록은 처음 열 때 새 이름으로 자연스럽게 바뀝니다(직접 지은 이름은 그대로).
- 저장 모양: `pets: { child1: { name, level, feedProgress, feedGranted, feedUsed, hall }, child2: { … } }`.
  예전 자정 성장 판(`startedAt`)이나 XP 판(`xp`·`awarded`)에서 올라온 기록은 이름·명예의 전당만 이어받고 **Lv.1 · 먹이 0 · 쿠폰 0**으로 시작합니다.

## 파일 구조

```
index.html                 화면 마크업
style.css                  크림/파스텔 스타일, 태블릿·모바일 반응형
app.js                     모든 기능(시간표·급식·달력·날씨·장보기·저녁·상태·우체통·루틴·모험·펫·잠금·백업)
data/family-vault.enc.json 암호화된 자료 볼트 (시간표·급식·공유 일정, AES-256-GCM)
manifest.json              홈 화면에 추가할 때 쓰는 설정
assets/                    가족 캐릭터 일러스트, 펫 10단계 그림(hamster-1~10.png · owl-1~10.png), 앱 아이콘
sync/Code.gs               폰↔태블릿 동기화용 Apps Script 웹 앱(urijip-sync) 코드
```

## 열리는 순서

1. 페이지를 열면 **가족 PIN 4자리 잠금 화면**이 가장 먼저 뜹니다.
2. PIN을 넣으면 브라우저의 Web Crypto가 `data/family-vault.enc.json`을 풀어
   시간표·급식·공유 일정을 **메모리에만** 올리고 대시보드를 그립니다.
3. PIN이 틀리면 복호화가 실패해 아무 자료도 보이지 않고 오류만 표시됩니다.
4. 이 기기에서 만든 기록(장보기·편지·루틴·메모 일정)은 같은 PIN 열쇠로
   `localStorage`에 암호화되어 저장돼요. 기기에 예전 기록이 있으면 잠금을 풀 때 자동으로 이어 붙습니다.
5. 새로고침하면 다시 잠깁니다.

## GitHub Pages에 올리기

1. 공개 저장소를 만들고 이 폴더의 파일을 저장소 최상위에 올립니다.
2. **Settings → Pages → Build and deployment** 에서 Source를 `Deploy from a branch`,
   Branch를 `main` / `(root)` 로 지정합니다.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소 이름>/` 로 열립니다.

## 자료(볼트) 갱신하기

시간표·급식·공유 일정이 바뀌면 평문 자료를 새로 받아 볼트를 다시 만들어 올립니다.

1. 평문 자료 두 개(시간표·급식, 공유 일정)를 준비합니다. **이 파일들은 저장소에 올리지 마세요.**
2. 같은 PIN으로 볼트를 다시 만듭니다(PBKDF2-SHA256 150,000회, AES-256-GCM, 16바이트 salt, 12바이트 IV).
   - `data/family-vault.enc.json` 형식:
     ```json
     {
       "format": "family-dashboard-vault", "v": 1,
       "kdf":    { "name": "PBKDF2", "hash": "SHA-256", "iterations": 150000, "salt": "<base64>" },
       "cipher": { "name": "AES-GCM", "length": 256, "iv": "<base64>", "data": "<base64>" },
       "createdAt": "2026-01-01T00:00:00Z"
     }
     ```
   - 복호화 결과는 `{ "school": {...}, "calendar": {...} }` JSON입니다.
3. 만든 파일을 `data/family-vault.enc.json` 에 덮어쓰고 커밋합니다.

## 기록과 백업

- 만든 기록은 이 기기 브라우저의 `localStorage`에 암호화되어 저장되고, 같은 가족 PIN을 쓰는 폰·태블릿과는 **암호문만** 주고받습니다(아래 동기화 항목).
- 오른쪽 위 **⚙️ → JSON 내보내기 / JSON 가져오기** 로 백업·복원합니다. 내보낸 파일은 평문이니 따로 보관하세요.
- 기기를 바꾸거나 브라우저 기록을 지우면 이 기기에는 남아 있지 않지만, 잠금을 열 때 클라우드에 올려 둔 최신 기록을 다시 불러옵니다.

## ☁️ 폰 ↔ 태블릿 동기화 (2026-11-20)

폰과 거실 태블릿이 같은 기록을 함께 봅니다. 별도 가입 없이 구글 앱스 스크립트 웹 앱 하나(`urijip-sync`)를 백엔드로 씁니다.

- **서버에 남는 것**: `{ v, updatedAt, enc }` 뿐입니다. `enc`는 화면에서 PIN으로 만든 열쇠로 **AES-256-GCM** 암호화한 문자열이라 서버·GitHub 어디에도 평문 가족 정보(이름·일정·편지)는 없습니다.
- **잠금을 열 때**: 이 기기 암호문과 클라우드 암호문의 `updatedAt`을 견줘 더 새것을 씁니다. 이 기기에서 풀지 못하는 옛 암호문은 `urijip-dashboard-v1-locked-backup`에 지우지 않고 남깁니다.
- **바뀌면**: 기기에 바로(디바운스 없이) 암호화 저장하고, 0.9초 뒤 클라우드로 올립니다. 창을 닫는 순간(`pagehide`/`beforeunload`)에도 한 번 더 씁니다.
- **다른 기기 변경**: 9초마다, 그리고 화면으로 돌아올 때(`visibilitychange`·`focus`) 클라우드를 확인해 `updatedAt`이 더 새면 화면을 다시 그립니다. 입력 중이거나 창이 떠 있으면 방해하지 않고 다음 차례로 미룹니다.
- 헤더의 **☁️ 동기화됨 / 동기화 중… / 오프라인** 표시를 누르면 지금 바로 맞춥니다.
- 서버 코드는 `sync/Code.gs`입니다(Apps Script 프로젝트 이름 `urijip-sync`, 배포: 웹 앱 · 실행 주체: 나 · 액세스 권한: 모든 사용자, URL 끝 `/exec`).
- **처음 켜는 순서**: 기록이 가장 최신인 기기(보통 거실 태블릿)를 먼저 열어 클라우드에 올린 뒤, 다른 기기를 열면 그 기록을 받아 갑니다. 먼저 연 기기의 기록이 기준이 되니, 새로 시작하기 전에 **⚙️ → JSON 내보내기** 로 한 번 백업해 두면 안전합니다.
- `sync/Code.gs` 의 `resetState` 를 Apps Script 편집기에서 한 번 실행하면 서버에 올린 암호문을 비울 수 있습니다(각 기기의 기록과 내보낸 백업은 그대로).
- 앱스 스크립트는 하루 실행 시간 제한이 있어, 한 화면을 하루 종일 켜 두면 9초 폴링이 부담이 될 수 있습니다. 이때는 헤더 표시가 `☁️ 오프라인` 으로 바뀌었다가 잠시 뒤 다시 붙습니다.

## 날씨 위치 바꾸기

날씨 카드의 **📍 서울** 버튼을 누르면 동네 이름으로 검색하거나 현재 위치를 쓸 수 있습니다.
고른 위치는 이 기기에만 저장됩니다. Open-Meteo 무료 API를 쓰기 때문에 API 키가 필요 없습니다.
인터넷이 끊기면 마지막으로 확인한 날씨를 그대로 보여 줍니다.

## 거실 태블릿에 상시 거치하기

1. 홈 화면에 추가하면 주소창 없이 전체화면(standalone)으로 열립니다.
2. PIN을 풀고 오른쪽 위 **☀️ 화면 켜짐** 을 눌러 **ON** 으로 두세요.
   화면이 자동으로 꺼지지 않게 유지되고, 그 선택은 이 기기에 기억됩니다.
   (브라우저가 화면 잠금을 풀면 화면으로 돌아오거나 손대는 순간 다시 잡습니다.
   이 기능을 지원하지 않는 브라우저에서는 조용히 안내만 해요.)
3. 자정이 지나면 **새로고침 없이** 날짜·오늘의 시간표·급식·캘린더가 새 날로 바뀝니다.
   날씨는 30분마다, 지금/다음 시간표 표시는 1분마다 새로 맞춰집니다.
   새로고침을 하지 않으므로 PIN 잠금이 풀린 채로 계속 떠 있을 수 있습니다.
4. 새 버전을 올리면 헤더에 **⬆ 새 버전** 배지가 뜹니다. 누르면 안내가 나오고,
   새로고침하면 PIN을 다시 입력해야 합니다(자동으로 새로고침하지는 않습니다).
